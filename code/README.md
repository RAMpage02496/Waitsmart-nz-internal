# Emergency Q

A Python/Tkinter app showing estimated Emergency Department wait times for Auckland
hospitals (NCEA Level 3 DigiTech, AS91906 & AS91907). Version 3 is the final version.

Note: the wait times are simulated, not real data.

## Requirements

- Python 3 (3.10 or newer)
- `pip install tkintermapview` (for the map in Version 3)
- Internet connection (the map loads online tiles)

## Run

Keep `EmergencyQ_Version3.py`, `hospitals.txt` and `suburbs.txt` in the same folder, then:

```
python EmergencyQ_Version3.py
```
